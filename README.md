# Capability Calculation

Simple step-by-step Python application for analyzing process capability (Cp, Cpk, Pp, Ppk) from M3 laboratory measurements.

The program validates 25 manufacturing orders, five measurements and one recorded average per order, then produces normality and X-bar/R control charts before calculating capability indices.

Run: `pip install -r requirements.txt` and `python main.py`.

This repository includes a reference Excel dataset for verifying the methodology against the Appendix F example.
